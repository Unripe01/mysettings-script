# 【前提条件】

- 既存サイトの **base ディレクトリ** には、現在公開中のHTMLがあります
- あなたはそれを「参考資料」として扱います
- 実装はすべて **new ディレクトリ** に新規作成してください
- base ディレクトリ内のファイルは **一切編集しません**

---

# 【構造に関する最重要ルール】

- **ページ構成（ページ数・URL単位の構成）は変更禁止**
  - 例：
    - index.html
    - about.html
    - activity.html
    - contact.html
    など
- 各ページが持つ「役割・目的」は踏襲してください
- ただし、**各ページ内の文章・表現・見せ方は全面刷新して構いません**
- HTML構造（DOM）は、読みやすさ・保守性を考慮して再設計してOK

---

# 【目的・トーン】

本サイトは  
**一般社団法人 ヒュッゲ美育協会** の公式Webサイトです。

対象ユーザーは：

- 教育・保育・看護・介護分野の従事者
- 子ども・高齢者・家族に関わる立場の人
- Webに詳しくない一般ユーザー
- 情報を「慎重に」「安心を求めて」閲覧する人

そのため、
**派手さ・トレンド感・LP的演出は不要**ですが、
同時に **「素人が作った感」「無料テンプレ感」も完全に排除**してください。

---

# 【デザイン指針】

- 落ち着いている
- 清潔感がある
- 情報が整理されている
- 押し付けがましくない
- 長時間読んでも疲れない

避けるべきもの：
- 強すぎるCTA
- マーケティング色の強いコピー
- 過剰な装飾・演出
- 不必要なトレンドデザイン

---

# 【画像の扱い】

- base ディレクトリに存在する画像素材は **すべて使用可能**
- 画像の差し替えは不要（新規追加は必要最小限なら可）
- 画像サイズ・縦横比が不揃いである前提で設計すること
- 以下を必ず考慮すること：
  - max-width
  - height: auto
  - object-fit
  - レスポンシブ対応

---

# 【技術要件】

- HTML / CSS / JavaScript を使用してよい
- jQuery の使用を許可します
- ただし、**技術デモのような実装は禁止**
- JavaScriptは以下の目的に限定して使用してください：
  - UIの自然な補助
  - ナビゲーション補助
  - 軽微なインタラクション
  - 読みやすさ・安心感の向上

---

# 【実装方針】

- ディレクトリ構成はシンプルに
- 外部ビルドツール不要
- S3にそのままアップロードして動作すること
- JS / CSS は分離してもよい
- パフォーマンスより「安定性・分かりやすさ」を優先

---

# 【アクセシビリティ配慮】

- コントラスト不足は禁止
- フォントサイズは小さくしすぎない
- 高齢者・視力が弱い人も想定
- 動きは控えめ、酔いやすい演出は禁止

---

# 【禁止事項】

- ページ構成の変更
- 過剰なアニメーション
- 3D表現
- ガラスモーフィズム
- 技術力を誇示する実装
- 開発者向けの説明文

---

# 【最終出力】

- **new ディレクトリ配下に配置される想定のファイル一式を出力すること**
- 各HTML / CSS / JS の内容をすべて提示すること
- 解説・補足・コメントは不要
