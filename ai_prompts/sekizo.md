# 【背景・ビジュアル（最重要）】

- body 背景は **position: fixed**
- カラートーンはブラック〜ダークグレー
- 背景画像として **heihachi.png** を使用

heihachi.png の扱い：
- キャラは等身大・全身画像
- **画面右側に配置**
- キャラの **右側は画面外に見切れてよい**
- **左半身のみが画面内に見える**構図
- 左から右にかけてフェードアウトする印象
- opacity / gradient / mask を用いて背景に自然に溶け込ませること

※ キャラは主役ではなく「空気感」
※ テキストの可読性を最優先

# 【データ取得（厳密指定）】

以下のURLから大会データを取得してください：

https://docs.google.com/spreadsheets/d/1PMCLjspifYxDzvo271waMHcjCHUJi9Jc-5ZE2RHOFkU/gviz/tq?tqx=out:json

このURLは **Google Visualization API形式** でレスポンスを返します。

重要事項：
- レスポンス冒頭に `/*O_o*/` が含まれる
- JSONは `google.visualization.Query.setResponse(...)` の形式
- `table.rows[].c[]` からデータを抽出する必要がある

列の意味：
- c[0] : タイムスタンプ（無視してよい）
- c[1] : 大会名
- c[2] : 参加日（Date形式）
- c[3] : 結果
- c[4] : 大会URL
- c[5] : 動画URL（YouTube）

実装要件：
- JavaScriptで文字列を整形し JSON を抽出
- 大会ログは **参加日降順** にソート
- 動画URLが空の場合はリンクを表示しない

具体的なデータ
```JSON
/*O_o*/
google.visualization.Query.setResponse({"version":"0.6","reqId":"0","status":"ok","sig":"357873569","table":{"cols":[{"id":"A","label":"タイムスタンプ","type":"datetime","pattern":"yyyy/MM/dd H:mm:ss"},{"id":"B","label":"大会名","type":"string"},{"id":"C","label":"参加日","type":"date","pattern":"yyyy/MM/dd"},{"id":"D","label":"結果","type":"string"},{"id":"E","label":"大会URL","type":"string"},{"id":"F","label":"動画URL","type":"string"}],"rows":[{"c":[{"v":"Date(2026,0,19,22,32,38)","f":"2026/01/19 22:32:38"},{"v":"サンプル鉄拳大会"},{"v":"Date(2026,0,19)","f":"2026/01/19"},{"v":"ぶっちぎりで優勝！"},{"v":"https://www.youtube.com/"},{"v":"https://www.youtube.com/"}]},{"c":[{"v":"Date(2026,0,19,22,32,38)","f":"2026/01/19 22:32:38"},{"v":"おあそび大会"},{"v":"Date(2026,0,18)","f":"2026/01/18"},{"v":"まけたぁーあかーん"},{"v":"https://www.youtube.com/"},{"v":"https://www.youtube.com/"}]}],"parsedNumHeaders":1}});
```
