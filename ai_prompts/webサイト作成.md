あなたは世界的なWebデザイン賞「Awwwards」を複数回受賞している
トップクラスのWebデザイナー兼フロントエンドエンジニアです。

以下の要件をすべて満たす、
**審美性・没入感・完成度の高いランディングページ（LP）**
のHTML/CSS/JavaScriptコードを生成してください。

# 【テーマ】
LP草案.md にあるように、健康を促進・インサイトを誘発させるような
「健康促進」のプロモーションWebサイト

# 【デザイン思想】
- Apple公式サイトのような「Bento Grid（ベントグリッド）」レイアウト
- 情報はすべてカード化し、余白と視線誘導を最優先
- 温かいモード基調、洗練された安心感
- 実案件レベルの完成度（デモ・教材感を出さない）

# 【ビジュアル表現】
- Glassmorphism（すりガラス表現）を多用
  - backdrop-filter: blur()
  - 半透明 + subtle border
- 背景には Grained Gradient（微細ノイズ入りグラデーション）
  - フラットな単色は禁止
- メインビジュアルは「空気感・浮遊感」を重視
- 高級プロダクト広告のトーンで
- 講師紹介の写真は、instructor.jpg を使ってください。
- 登録時プレゼントの写真は benefit_card.png を使ってください。
- その他写真や画像が足りない場合は、Unsplash を使うか、もしくは自身で画像生成を行ってください。

# 【アニメーション・動き】
- スクロール連動の Fade-in / Slide-up アニメーション
- アニメーションは「やりすぎない」「上品」「60fps」
- CTAボタンには hover 時の
  - subtle glow
  - 微細なスケール変化
- すべて CSS + JS で実装（ライブラリ依存を減らす）

# 【3D表現】
- Three.js を CDN 経由で使用
- ヒーローセクション中央に抽象的な 3D オブジェクトを配置
- マウスカーソルにゆっくり追従し、緩やかに回転
- 「意味のある派手さ」ではなく「雰囲気を作るための3D」

# 【技術スタック】
- HTML5
- Tailwind CSS（CDN読み込み、カスタムCSS併用OK）
- Three.js（CDN）
- 外部ビルドツール不要（単一HTMLで動作）

# 【画像素材の扱い】
- 商品画像・背景画像は
  - Unsplash 等の実在URLを使用すること
  - placeholder画像は禁止
- スニーカー・テック・近未来系で統一

# 【コンテンツ構成】
- Hero（ブランドメッセージ + 3D）
- 特徴セクション（軽量性 / 空力 / デザイン）
- プロダクトカード（Bento Grid）
- ブランド思想セクション
- 強いCTA（Buy / Explore）

# 【重要】
- コメントは最小限
- 読みやすさより「かっこよさ」を優先
- コードはコピペ即動作すること
- デザイン妥協は禁止
